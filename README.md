# Hanif Awol Seid portfolio
Static site: HTML, CSS, vanilla JS. No build step.
**Local:** open `index.html`, or run `python3 -m http.server` and visit localhost:8000.
**Deploy:** upload the folder to Netlify, GitHub Pages, or any static host. Set 404.html as the error page.
**To finish:** replace placeholder projects in `main.js` (`projects`), paste your biography in `about.html`, set `CONTACT_EMAIL` in `main.js`. Fonts load from Google Fonts.
